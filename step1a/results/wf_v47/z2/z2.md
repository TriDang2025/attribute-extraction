# Z2 replay: what passes the loop-2 evidence check under other rules

`scripts/replay_v47.py` on the cached v4.6 Step 1b answers; no LLM calls, no gold. bge-m3 + GLiNER on the laptop CPU, 23 min for both sets
(log `replay.log`). Per name: `<set>/names.csv`; spans: `<set>/spans.json`.

**Check:** the base replay gives the same keep decision and the same spans as the v4.6 run for every voted name (dev50 42/42, dev50b 30/30).

**Threshold:** value Jaccard 0.5, set on dev50 (0.3 / 0.5 / 0.7 tried: no value of t passes a better dev50 set than base, see r1) and used
unchanged on dev50b.
