## Task 7: split back

Rule: a group of A s012 with >= 2 clusters is split when two of its clusters are a keep-apart pair or their names form a role pair (row "all names": the names in the 3 orders and the vote; row "vote names": the vote names only, as the v3.8 code check reads them) (departure / destination, leave at / arrive by, location / address). Every cluster in a conflict seeds a column (biggest first; a seed joins an existing column only when it conflicts with none of its seeds, choosing the column of its most similar seed); other members go to the column of the most similar seed (bge-m3 centroid cosine). Each column is a new group with the vote name of its biggest named cluster; a repeated name gets the top value of the cluster in brackets so that the columns stay distinct.

- mentions of a split group from a cluster the group did not list: 0
