- alpha 0 reproduces the adopted clusters exactly (dev50 963 and dev50b 801 mentions: same cluster ids, same replayed columns and found L2).

- Replay limit: a changed cluster has no cached name. Strict = only clusters with Jaccard >= 0.8 keep their name (lower bound); lenient = a changed cluster also takes the old cluster that holds half of its mentions (upper bound, hides fragmentation). Real value needs a GPU rerun.

## Choices and definitions

- Context text: turn text from 4 words left to 2 words right of the value inside its turn (speaker prefix cut), the value itself replaced by its type tag `<<[TAG]>>` (masked, not dropped), other values of the dialogue masked by their type tags (step2.window_texts); bge-m3 (same encoder and cache as the value vectors), unit vectors.
- v = unit((1 - alpha) v_value + alpha v_context), v_value = the adopted value vector (shape text for codes), used in the agglomerative step (average linkage, by stage-1 entity and value type) and in the fold (min size 2, cosine 1 - t, booking check).
- t grid 0.4 (adopted), 0.3, 0.25, 0.2, 0.15, 0.1 with fold cosine 1 - t; the same grid for alpha 0 as control. Stage-1 entities are kept (only stage 2 is rerun).
- Mixed-role cluster: two gold L2 attributes of the entity, each >= 3 mentions and >= 25% of the cluster. Fragmented attribute: majority (>= 50%, >= 3 mentions) of >= 2 clusters. S3 attributes: gold attributes with no cluster passing the scorer found rule (trace_v50 clusters checkpoint, attributes mostly in the scored entity). Scored entities = train / hotel / restaurant.
- Selection on dev50: alpha > 0, K <= 1.5 x adopted, then most lenient found L2, fewest mixed clusters, fewest fragmented attributes, smallest alpha. dev50b scored with the same alpha and t.
- Found L2 = G3 rule: v4.9 set (loop 1 + 2, human check) minus loop-1 finds lost plus new ones; columns replayed from the cached final columns (reconcile and duplicate check already applied); empty cached columns stay.
- Gold only to score and trace. No MultiWOZ words or lists in the new code (the adopted value shapes of F_m2_t06_bk are unchanged).
